# 📦 Dependency Management with uv

This project uses **uv** for fast, reliable dependency management.

## 🚀 Quick Commands

### For Team Members (First Time Setup)
```bash
# After cloning the repo
uv sync
```
That's it! This creates your virtual environment and installs everything.

### For Adding New Packages
```bash
# Add a package
uv add package-name

# Add with specific version
uv add numpy==1.24.3

# Add development-only packages
uv add --dev pytest black

# After someone adds packages:
uv sync  # Updates your environment
```

### For Removing Packages
```bash
# Remove a package
uv remove package-name

# Sync to update
uv sync
```

### For Updating Packages
```bash
# Update a specific package
uv add package-name --upgrade

# Update all packages
uv sync --upgrade
```

## 📁 Key Files

- **`pyproject.toml`** - Project configuration and dependencies
  - Edit this to add/remove packages manually
  - Or use `uv add` / `uv remove` commands
  
- **`uv.lock`** - Locked dependency versions
  - Auto-generated by uv
  - **DO commit this** - ensures everyone has identical versions
  - Don't edit manually
  
- **`requirements.txt`** (legacy)
  - Kept for reference
  - Use `pyproject.toml` instead

## 🔄 Workflow

### Scenario 1: You Need a New Package
```bash
# Add it
uv add scikit-image

# Commit both files
git add pyproject.toml uv.lock
git commit -m "feat: Add scikit-image for image processing"
git push
```

### Scenario 2: Someone Else Added a Package
```bash
# Pull their changes
git pull

# Sync your environment (installs new package)
uv sync
```

### Scenario 3: Something's Broken
```bash
# Remove and recreate environment
rm -rf .venv  # Mac/Linux
# rmdir /s .venv  # Windows

# Resync from lockfile
uv sync
```

## 🎯 Why This Workflow?

✅ **Fast** - 10-100x faster than pip  
✅ **Reproducible** - `uv.lock` ensures everyone has same versions  
✅ **Simple** - One command: `uv sync`  
✅ **Modern** - Industry best practice  

## 🆘 Troubleshooting

**"uv: command not found"**
```bash
pip install uv
```

**"Failed to resolve dependencies"**
```bash
# Check pyproject.toml for conflicts
# Try removing problematic package and re-adding
uv remove problematic-package
uv add problematic-package
```

**"Wrong Python version"**
```bash
# uv automatically uses Python 3.10+
# If you need specific version:
uv venv --python 3.10
```

**"Package not found after uv sync"**
```bash
# Make sure you activated the environment
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Mac/Linux
```
